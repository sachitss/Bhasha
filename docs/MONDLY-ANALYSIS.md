# Mondly by Pearson – analysis and what Bhasha adopts

Date: 2026-10-10. Sources: public reviews ([Lingopie, 2026](https://lingopie.com/blog/mondly-review/), [Actual Fluency](https://actualfluency.com/mondly), [FluentU](https://www.fluentu.com/blog/mondly-review/)). Bhasha has no affiliation with Mondly or Pearson.

## What Mondly offers

| Area | Mondly | Bhasha before 1.3 |
|---|---|---|
| Lesson format | Topic packs on a map; daily lesson of 5–10 min, ~12 exercises across listening, reading, writing, speaking | Adaptive daily plan 10–60 min, four skills, spaced repetition |
| Conversation | Scripted chatbot scenarios (café, directions, doctor); pick a suggested reply or speak; speech recognition paid | None – single-sentence pronunciation practice only |
| Vocabulary | Themed words, image matching, word order, swipe answers | Words in context, matching, word order, notebook |
| Grammar | Very little direct teaching; verb conjugation tables reachable from a verb | Implicit only (examples, notes) |
| Numbers | Taught inside topic lessons | Numbers 1–10 only |
| Motivation | Streaks, points/stars, leaderboards, weekly quiz, monthly challenge | Streak, XP, goal ring, per-skill progress |
| Learn via any language | Yes (41 languages) | Yes (5 languages, any direction) |
| Extras | AR app, VR (headset), Mondly Kids | Lock-screen words, widget, Glance mode, offline native audio |

**Strengths reviewers name:** short, varied daily lessons; native audio; learning through your own language; chatbot to rehearse real situations; habit features.
**Weaknesses reviewers name:** almost no grammar explanation; rigid chatbot that fails off-script; little content beyond beginner level; repetition; speech features behind the paywall; AR/VR gimmicky.

## What Bhasha 1.3 adopts – and does differently

1. **Interactive conversations** (Mondly's chatbot): six real situations (café, meeting someone, hotel, directions, market, doctor) in all five languages, native audio for every line, reply by choosing or by speaking (browser speech recognition), with romanisation and an optional translation toggle. Wrong replies are marked and cost a point instead of ending the dialogue. *Different:* free, offline audio, and works in both directions between any two of the five languages.
2. **Grammar** (Mondly's biggest gap): 16 short topics – a one-line rule in the learner's language, a tappable table with native audio, and a generated practice round. German (sein/haben, present tense, vowel change, der/die/das), Spanish (ser/estar, -ar, -er/-ir, el/la), English (be/have, -s, irregular past), Nepali (हुनु, present tense), Korean (-아요/-어요, 이에요/예요, particles). Article and particle questions are generated from the vocabulary, so practice never runs out.
3. **Numbers 0 – 1,000,000**: explore 0–1,000, type any number up to a million and see/hear it, "Steps to a million" (1,000 → 10,000 → 100,000 → 1,000,000 in tens), and a 10-question practice. Native audio is built from recorded parts (e.g. "three hundred and" + "forty-seven"), so every number is spoken by the native voice offline. Nepali uses lakh grouping and Devanagari digits; Korean uses 만.
4. **Vocabulary games** (Mondly's game feel): speed round (60 s), memory pairs, spelling, number rush – with best scores per language.

Not adopted: leaderboards (need accounts and a server), AR/VR (hardware, weak value per reviews), paywalled speech.
