Bhasha 1.3.0 – numbers, games, conversations, grammar

- Numbers 0 – 1,000,000 in all five languages: explore, type any number and hear it, "Steps to a million", practice rounds. Every number is spoken by the native voices
- Vocabulary games: speed round, memory pairs, spelling, number rush – best scores per language
- Interactive conversations: café, meeting someone, hotel, asking the way, market, doctor – answer by choosing or speaking, with translations on demand
- Grammar: 16 topics with short rules, tables with native audio and generated exercises (German, Spanish, English, Nepali, Korean)
- About 2,200 new native audio clips
- Includes everything from 1.2.0

Installers: see the files below. Unsigned builds show a security prompt on first launch; see docs/RELEASE.md.
