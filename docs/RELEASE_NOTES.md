Bhasha 1.2.0 – German · English · Nepali · Korean · Spanish

- New language: Spanish (Español), with native voices Elvira (female) and Alvaro (male) and a Spanish interface
- More content in every language: 172 words in 23 topics, 40 travel phrases (new: café, shopping, sightseeing), 15 phrases, 6 reading texts
- The four skills: choose a focus on listening, reading, speaking or writing; vocabulary stays the core. Progress shows accuracy per skill
- New exercises: matching pairs, word order, dictation, sentence translation, write your own sentence, reading texts with tap-to-translate and questions
- Active notebook: meaning, own sentence, synonyms and notes for each word; add your own words; dictionary lookup (Oxford for English); CSV export
- Passive exposure: Android widget for the home and lock screen, lock-screen word notifications (Android/iOS), Glance mode on every device
- First-run questions set languages, level, skill focus and daily time
- Includes everything from 1.1.0

Installers: see the files below. Unsigned builds show a security prompt on first launch; see docs/RELEASE.md.
